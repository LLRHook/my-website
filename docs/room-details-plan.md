# Room close-ups

The computer now opens a larger monitor when powered on. Its power state and boot
progress remain in `Workspace`; moving between the room and the close-up does not
create another computer or another boot timer. A folder opens the existing reading
window. Only one modal is open at a time, and closing it returns focus to a room
control.

Room objects open a native dialog with a larger illustration or photograph and a
short caption. SVG crops use the original room artwork, so they stay sharp when
enlarged. Photos keep their source proportions, with a link to the original file.
The cat still responds directly to a greeting and also has its own close-up.

The Peru postcard uses Victor's own photograph shared on September 4, 2026. Public
copy identifies only Peru and the September 2026 trip. It does not reveal chat
names, hotels, or a precise current location. The conference photo has no verified
venue or capture date, so the caption does not invent either. Hobby descriptions
use interests confirmed by Victor or his own messages.

Validation: exercise ordinary and reduced motion, startup and shutdown, Escape,
Tab wrapping, return focus, related-app navigation, phone layouts, and repeated
open/close cycles. Ambient room motion pauses behind both kinds of close-up. The
user-triggered computer zoom remains separate from paused ambient motion.
